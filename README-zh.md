# 锻器工作站

[English](README.md) | **简体中文**

MiXianTu 的可选附属（`mxt_forging`）。提供锻造台、锻打流程、蓝图、方式与工具/图纸绑定。

客户端与服务端都需安装本附属、MiXianTu 及本体要求的前置。工作站的方块与物品由本附属提供，符笔、朱砂、符纸、丹药、符箓与其他共享材料和产物仍使用本体物品。所有附属物品都放在 **MiXianTu 创造模式物品栏**中。

本附属提供工作流程；具体配方、蓝图和数值仍需数据包或内容包配置。工作站与工艺数据使用 `mxt_forging:*` 标识，不提供旧 `mxt:*` ID 的别名或迁移。已有世界移除附属会丢失对应工作站与专用流程数据，请先备份。

客户端和服务端均需安装 Jupiter，本附属通过它提供独立配置入口。
