# Forging Workstations

**English** | [简体中文](README-zh.md)

An optional MiXianTu addon (`mxt_forging`). Provides the forge table, forging workflow, blueprints, methods and
tool/blueprint bindings.

Install on both the client and server, along with MiXianTu and its required dependencies. The addon owns its workstation
blocks and block items. Brushes, cinnabar, paper, pills, talismans and other shared materials and outputs remain
MiXianTu items. All addon items appear in the **MiXianTu creative tab**.

This addon provides workflows; datapacks or content packs supply recipes, blueprints and gameplay values. Workstation
and process identifiers use `mxt_forging:*`, without aliases or migration for the old `mxt:*` IDs. Removing the addon
from an existing world removes its workstations and process data; back up the world first.

Jupiter is required on both sides and provides the addon's configuration entry.
